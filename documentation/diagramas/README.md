# Diagramas editables

Fuentes Mermaid independientes preservadas del código original. Se pueden abrir
con un editor compatible o importar en la herramienta elegida por el autor.

| Archivo | Contenido |
|---|---|
| arquitectura.mmd | Componentes y recorrido fuente → consumidores |
| erd-fuente.mmd | Relaciones de las tablas operacionales seleccionadas |
| modelo-ventas.mmd | Estrella, grano y claves |
| etl-inicial.mmd | Primer flujo histórico; el incremental vigente se documenta aparte |
| incremental-y-scd.mmd | Publicación, SCD y watermark |
| alertas.mmd | Tarea transaccional, evaluación, reintento y panel |

Los diagramas PNG que el usuario incorpore en los documentos son presentaciones
complementarias. Estas fuentes conservan la edición aunque se sustituya un bloque
Mermaid por una imagen. No se modifican las exportaciones del usuario.
